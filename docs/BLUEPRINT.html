BLUEPRINT · KOSMATE v0.1 · 31 OKT 2026

Poco X3 NFC nganggur → teman kos yang bisa diajak ngomong

Jawabannya: bisa, dan prototipenya sudah jalan — bukan mockup. Suara real-time, memori yang inget hidup lu, tiga mode (temen / tutor / kerja), dan semuanya jalan di HP itu sendiri tanpa server sewaan.

● prototipe teruji jalan LLM: API key lu sendiri TTS: Fish Audio · gratis biaya ≈ Rp15 rb/bulan latency 1,5–3,5 s
01 — KEPUTUSAN

Layak, tapi bukan "beli alat baru"

Yang lu butuhkan cuma 3 hal yang sudah lu punya + 1 speaker.

1 HP

Poco X3 NFC: Snapdragon 732G, RAM 6GB. Cukup buat jadi otak + mic + speaker + layar sekaligus.

1 key

API LLM OpenAI-compatible punya lu. Model gratis (deepseek-flash-free / gemini-flash-lite) sudah lebih dari cukup buat ngobrol.

1 speaker

Speaker aktif ke jack 3.5mm. Ini yang bikin dia kerasa "ada di kamar", bukan aplikasi di HP.

02 — ARSITEKTUR

Satu HP, tiga lapisan

Kenapa gak pakai app jadi? Karena yang bikin "real-time" itu kendali atas tiap milidetik, dan itu cuma bisa kalau pipeline-nya punya sendiri.

  🎙 mic ──► Chromium / Fully Kiosk  (web UI, VAD, Web Speech API)
        │        STT streaming id-ID, gratis
        ▼
   FastAPI :8080  ── satu proses di Termux, tanpa root, tanpa Docker
        ├─ /api/chat ─► LLM API lu  (SSE, token keluar satu-satu)
        ├─ /api/tts  ─► Fish Audio  ─► fallback edge-tts    🔊 speaker
        ├─ /api/stt  ─► Fish ASR    ─► fallback whisper.cpp
        └─ memori     ─► SQLite + FTS5: fakta bertanggal + episode lama

kenapa memori bukan cuma "vector database"

Karena hidup lu berubah: jadwal semester baru, kos pindah, target ganti. Fakta butuh waktu (valid_at / invalid_at), bukan cuma kemiripan makna. Jadi yang dipakai: tabel fakta berstruktur + FTS5 + recency — akurat, jalan tanpa GPU, tanpa biaya embedding.

04 — LATENCY

Budget "kerasa hidup": di bawah 1,5 detik

Ini yang bikin asisten gagal atau enak diajak ngobrol. Target realistis sekarang 1,5–3,5 s; target berikutnya <1,2 s.

TahapSekarangCara nurunin
VAD (deteksi lu selesai ngomong)300–900 msturunin ambang jeda ke 600 ms
STT200–500 msstreaming, jangan kirim file utuh
LLM token pertama300–2000 msmodel flash/free, hindari reasoning model
TTS byte pertama400–1500 msFish > edge-tts, cache kalimat sapaan

Trik utamanya: balasan dipecah per kalimat, dan tiap kalimat langsung disintesis sambil model masih menulis sisanya. Jadi lu dengar suara sebelum jawaban selesai ditulis.

05 — ROADMAP

Empat fase, tiap fase kepakai

P0 · Fondasi SUDAH JALAN

Voice loop, memori fakta, 3 mode, sapaan proaktif, UI kiosk.

P1 · Bikin betah 1–2 MINGGU

  • Wake word "Kai" — gak perlu ketuk lagi
  • Flashcard SRS Logika & Basis Data: dia yang nanya, lu jawab pakai suara
  • Jurnal + ringkasan malam tiap jam 22: "hari ini lo gimana"
  • Barge-in — bisa motong jawabannya di tengah
  • Deadline & tugas dari obrolan

P2 · Bikin tahan lama 2–4 MINGGU

  • Otak pindah ke STB Armbian 24/7, HP jadi satelit (gak panas, gak takut mati)
  • whisper.cpp lokal → STT gratis, offline, suara gak keluar HP
  • Kloning suara sendiri (rekam 1 menit di Fish Audio)
  • Satelit kedua di dapur/kamar mandi

P3 · Bikin nyambung BULAN 2

  • Kalender kampus, Obsidian/Notion, Home Assistant (lampu & AC)
  • Kontrol dari Telegram saat di luar
  • Sleep mode: suara pelan, cerita pendek, auto-off
  • Versi native Kotlin + foreground service = always-on sejati

08 — MULAI

Tiga perintah, lima belas menit

# di Termux (dari F-Droid, bukan Play Store)
cd kosmate
bash scripts/install.sh     # python, ffmpeg, venv, deps
cp .env.example .env        # isi LLM_API_KEY (+ FISH_API_KEY)
termux-wake-lock && bash run.sh
# buka http://127.0.0.1:8080 di Chrome HP

Foldernya sudah lengkap: kos/ (otak), web/ (UI orb), scripts/ (install, kiosk, smoke test), README.md (panduan + jebakan yang sudah ketemu).

satu hal yang paling menentukan

Bukan model, bukan API. Speaker-nya. Suara yang keluar dari speaker kecil HP bikin dia kerasa gadget; suara dari speaker ruangan bikin dia kerasa teman satu kamar. Itu pembeda terbesar antara "proyek iseng" dan "ada yang nemenin gw di kos".
