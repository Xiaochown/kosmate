Pasang AI teman kos di Poco X3 NFC

Ikuti berurutan. Tiap langkah ada perintahnya, dan ada contoh output yang benar — kalau beda, langsung ke bagian 10. Total waktu santai ±40 menit.

● 12 bagian tanpa root tanpa VPS biaya Rp0 progress kesimpan otomatis

Males ngikutin 12 bagian? Ada installer otomatis yang ngerjain semuanya (benerin pip, install dependency, tulis .env, tes otak & suara, nyalain server, set autostart + sshd). Cukup satu baris, lalu tempel API key sekali saat ditanya:

unzip -o /sdcard/Download/kosmate/kosmate.zip -d ~/ && bash ~/kosmate/scripts/autoinstall.sh

Sisanya tetap berguna kalau lu mau ngerti bagian dalamnya, atau kalau nanti ada yang perlu dibenerin manual.

00 — SEBELUM MULAI

Yang harus ada di meja lu

Cek dulu, biar gak berhenti di tengah jalan.

Poco X3 NFC yang ada WiFi-nya, plus charger.

API key LLM yang udah lu punya (yang biasa lu pakai buat ngoding). Formatnya biasanya sk-...

Speaker — ini opsional tapi paling ngaruh. Speaker aktif yang colok ke jack 3.5mm (±150rb). Tanpa ini dia tetap jalan, tapi suaranya dari speaker HP.

01 — KENALAN 30 DETIK

Apa yang sebenernya jalan di HP lu

Biar pas error lu tahu bagian mana yang rusak.

Ada tiga bagian, semuanya di HP yang sama:

1. Termux = dapurnya 2. Python = otaknya 3. Chrome = mata, telinga, mulut

Termux itu aplikasi yang ngasih lu terminal Linux di Android. Python jalan di dalamnya: nyimpen memori, nyusun prompt, manggil LLM, bikin suara. Chrome yang ngambil suara lu lewat mic, nampilin orb, dan muter suara balasannya.

Keduanya harus di HP yang sama. Kalau browser-nya di HP lain, Chrome bakal blokir mic — karena dianggap koneksi gak aman. Ini bukan bug, ini aturan browser.

02 — APP DASAR

Install 4 aplikasi

Termux wajib dari F-Droid. Yang dari Play Store sudah usang dan paketnya bakal gagal.

Buka Chrome → ketik f-droid.org → tap tombol Download F-Droid → buka file APK yang ke-download → kalau muncul peringatan, pilih Settings → izinkan Install unknown apps untuk Chrome → balik dan install.

Buka F-Droid (ikonnya biru), tunggu daftar app muncul, lalu cari dan install tiga ini satu per satu:

TermuxTermux:APITermux:Boot

Kalau pencarian lambat, tap ikon Search di kanan atas dan ketik manual. Jangan ambil yang namanya “Termux (Google Play)” atau fork lain.

Buka Termux sekali, tunggu sampai muncul prompt ~ $. Kalau ada tulisan “Installing bootstrap” di awal, tungguin sampai selesai. Setelah itu tutup dulu.

Matikan optimasi baterai buat Termux — ini yang bikin dia mati sendiri kalau layar mati:

Settings (HP) → Apps → Termux → Battery → pilih Unrestricted / No restrictions. Di MIUI namanya bisa Battery saver → No restrictions.

Buka Termux:Boot sekali (cuma perlu dibuka, gak ada yang diatur). Ini yang nanti bikin Kosmate nyala sendiri tiap HP restart.

Kalau empat langkah ini beres, sisa semuanya cuma ngetik perintah di Termux. Gak ada yang perlu di-root.

05 — INSTALASI

Satu perintah, jalan sendiri

Yang dipasang: python, ffmpeg, uv, virtualenv, fastapi, httpx, edge-tts. Butuh koneksi internet.

cd ~/kosmate
bash scripts/install.sh

Butuh 5–15 menit kalau HP baru pertama kali. Ini normal — sebagian paket dikompilasi di HP.

ujungnya harus begini: ================================================ selesai. langkah berikutnya: 1. cp .env.example .env lalu isi LLM_API_KEY 2. bash scripts/termux-start.sh 3. Chrome -> http://127.0.0.1:8080

Kalau muncul tulisan “edge-tts tetap gagal” — jangan panik, itu cuma suara cadangan gagal dipasang. Lu tetap bisa lanjut; nanti di .env pakai Fish Audio untuk suara (bagian 06).

Kalau sempat muncul error bad interpreter: python3.13 — itu pip lama yang nunjuk ke python yang sudah di-upgrade. Script versi baru otomatis benerin (lewat ensurepip / python-pip), jadi cukup jalankan ulang bash scripts/install.sh. Kalau tetap gagal: python -m ensurepip --upgrade lalu ulangi.

Kenapa project ini TIDAK pakai FastAPI: pydantic (dependency FastAPI) butuh pydantic-core yang ditulis Rust, dan belum ada versi siap-pakai untuk Android aarch64 + Python 3.14. Hasilnya selalu metadata-generation-failed / maturin error. Server-nya pakai Starlette yang murni Python — semua fitur yang dipakai (routing, streaming, upload, static file) sudah ada di sana.

Cek hasil instalasi:

bash scripts/termux-diag.sh

Yang penting baris import fastapi dan import uvicorn harus [ok]. Sisanya boleh belum.

06 — KONFIGURASI

Isi .env (bagian paling gampang salah)

Empat baris wajib. Tanpa spasi sebelum/sesudah tanda =.

cd ~/kosmate
cp .env.example .env
nano .env

nano itu editor teks di dalam Termux. Panah keyboard HP gak jalan — geser kursor dengan tap di baris yang mau diedit.

Isi minimal empat baris ini (contoh pakai TeamORouter):

LLM_BASE_URL=https://api.teamorouter.com/v1
LLM_API_KEY=sk-punyalu-disini
LLM_MODEL=deepseek-v4-flash-free
LLM_MODEL_FALLBACK=gemini-3.5-flash-lite

Kalau pakai Fish Audio, tambahkan:

TTS_PROVIDER=fish
FISH_API_KEY=fk-punyalu-disini
FISH_MODEL=s2.1-pro-free
FISH_REFERENCE_ID=

FISH_REFERENCE_ID boleh kosong dulu — suara default tetap keluar. Nanti diisi ID suara favorit lu dari fish.audio.

Simpan & keluar dari nano: tekan CTRL di toolbar Termux (ada tombol kecil di atas keyboard) lalu O → Enter → lalu CTRL + X.

Kalau toolbar CTRL gak ketemu: tombol volume-down + O berfungsi sebagai Ctrl+O di Termux.

Verifikasi tanpa nampilin key-nya:

grep -E '^(LLM_MODEL|TTS_PROVIDER)=' .env
grep -c '^LLM_API_KEY=sk-' .env
harusnya: LLM_MODEL=deepseek-v4-flash-free TTS_PROVIDER=auto 1

Kalau hasil terakhir 0, berarti key belum kesimpen atau formatnya bukan sk-. Ulangi 06a.

07 — NYALAIN

Tes pertama: dia harus nyapa lu

Kalau bagian ini lolos, 90% pekerjaan selesai.

cd ~/kosmate
bash scripts/termux-start.sh

Script ini ngunci biar Android gak bunuh Termux, terus buka Chrome otomatis ke 127.0.0.1:8080. Kalau Chrome gak kebuka sendiri, buka manual.

di Termux harusnya: [kosmate] wake lock aktif Kosmate jalan di http://0.0.0.0:8080 INFO: Application startup complete.

Jangan tutup Termux. Pindah ke Chrome (pakai recent apps, jangan back dari Termux — back bisa matiin prosesnya).

Di Chrome: http://127.0.0.1:8080 → muncul layar orb gelap + judul Kai. Kalau ada popup minta mikrofon → tap Allow.

cek cepat kalau layar aneh: http://127.0.0.1:8080/api/health harusnya: {"ok":true,"name":"Kai","llm":"deepseek-v4-flash-free","llm_key":true,...}

Tap layar sekali (buat buka izin audio otomatis — Chrome gak boleh bunyi tanpa disentuh), lalu ketuk orb dan bilang: “halo Kai, kenalin gue Faa”.

Yang bakal lu lihat berurutan: tulisan “gue dengerin…” → transkrip muncul → “mikir…” → orb ungu → suara.

Tes memori: bilang “inget ya, gue alergi kacang”. Tutup Chrome, buka lagi, tanya “gue alergi apa?”. Kalau dia jawab kacang — memori jalan.

Kalau sampai sini sukses: lu udah punya asisten suara yang punya ingatan. Sisanya cuma bikin dia nyala sendiri dan nyaman dipakai.

08 — OTOMATIS

Biar nyala sendiri tiap HP restart

Dua bagian: Termux autostart, dan browser fullscreen.

A. Termux:Boot

mkdir -p ~/.termux/boot
cp ~/kosmate/scripts/termux-boot.sh ~/.termux/boot/10-kosmate.sh
chmod +x ~/.termux/boot/10-kosmate.sh
ls ~/.termux/boot/
harusnya:10-kosmate.sh

B. Fully Kiosk Browser

Install Fully Kiosk Browser dari Play Store (versi gratis cukup). Ini bikin Chrome-nya fullscreen, layar gak mati, dan auto-restart kalau crash.

Buka app → Settings → Web Content Settings → Start URL = http://127.0.0.1:8080

Lalu nyalakan: Web Auto Reload on Idle, Restart App on Crash.

Settings → Device Management → nyalakan Keep Screen On, Launch on Boot, Prevent Sleep.

Balik ke Settings → Permissions → izinkan Microphone (wajib, kalau nggak dia bisu).

Matikan optimasi baterai buat Fully Kiosk juga (Settings HP → Apps → Fully Kiosk → Battery → Unrestricted).

Tes: restart HP. Tunggu ±1 menit. Kosmate harusnya muncul sendiri dan nyapa lu sesuai jam.

09 — PAKAI SEHARI-HARI

Cara ngobrol sama dia

Tiga tombol yang perlu lu hafal.

Mode (chip di atas orb): temen buat ngobrol & curhat, tutor buat belajar (dia jelasin terus nanya balik), kerja buat tugas & deadline.

Tombol memori (kiri atas, tulisan n fakta): lihat semua yang dia inget. Tap × buat hapus fakta yang salah — dia langsung lupa.

Gear ⚙: ganti suara, nyalain dengerin otomatis (biar gak perlu ketuk orb terus), atur jeda dengerin (900 ms default — turunin ke 600 kalau dia suka motong omongan lu, naikin ke 1200 kalau lu suka mikir dulu).

Kalau salah dengar: dia nampilin transkrip di tengah layar. Tinggal ulangi. Ketik manual juga bisa lewat kolom bawah.

Backup memori (1× seminggu cukup): buka http://127.0.0.1:8080/api/export → Chrome simpan sebagai file JSON. Simpen di Drive.

10 — KALAU RUSAK

Gejala → sebab → obat

Tap buat buka. 90% masalah ada di lima pertama.

curl error: “cannot locate symbol ngtcp2_conn_get_tls_early_data_rejected2”

Penyebab: Termux setengah ke-upgrade — libcurl.so versi baru minta simbol dari libngtcp2 yang masih versi lama. Efeknya berantai: curl mati → git clone mati → pkg juga mati (pkg ngecek mirror pakai curl) → pip ikut rusak.

Obat: jangan pakai pkg (dia butuh curl). Pakai apt langsung, ini yang disarankan pesan error-nya sendiri:

apt update && apt full-upgrade -y
python -m ensurepip --upgrade
curl -sI https://github.com | head -1   # harus HTTP/2 200
git --version
python -m pip --version

Kalau apt juga bermasalah, paksa reinstall paket yang bentrok: apt install --reinstall -y libngtcp2 libngtcp2-crypto-ossl curl

FileNotFoundError: “/tmp/kos.sh” waktu bootstrap

Penyebab: Termux tidak punya folder /tmp (yang ada $PREFIX/tmp dan $TMPDIR). Script yang menulis ke /tmp akan gagal.

Obat: pakai ~/ atau $TMPDIR. Contoh bootstrap lewat python yang benar:

python -c "import urllib.request as u,os;d=u.urlopen(u.Request('https://api.github.com/repos/Xiaochown/kosmate/contents/install.sh',headers={'Accept':'application/vnd.github.raw','User-Agent':'kosmate'}),timeout=60).read();p=os.path.expanduser('~/kos.sh');open(p,'wb').write(d);os.environ['KOSMATE_FORCE_ZIP']='1';os.execvp('bash',['bash',p])"
Error “bad interpreter: python3.13” waktu install

Penyebab: lu pernah upgrade paket python di Termux; file pip lama masih nunjuk ke python3.13 yang sudah dihapus.

python -m ensurepip --upgrade
python -m pip --version
bash scripts/install.sh

Kalau ensurepip ikut gagal: pkg install -y python-pip lalu ulangi. Yang penting: pakai python -m pip, jangan perintah pip langsung.

Error “pydantic-core / maturin / rustc target not supported”

Penyebab: ini kalau lu pasang FastAPI manual. pydantic-core ditulis Rust dan belum bisa dibangun untuk Android aarch64 + Python 3.14.

Obat: project ini sudah nggak butuh FastAPI/pydantic. Kalau lu sempat install manual, hapus dan pasang versi Starlette:

python -m pip uninstall -y fastapi pydantic pydantic-core
bash scripts/install.sh
Mic gak jalan, ketuk orb tapi gak ada reaksi

Penyebab: Chrome blokir mic karena alamatnya bukan 127.0.0.1/localhost. Ini paling sering — misal lu buka pakai IP LAN.

Obat: pastikan URL-nya persis http://127.0.0.1:8080. Lalu Chrome → titik tiga → Settings → Site settings → Microphone → pastikan 127.0.0.1 diizinkan.

Dia jawab di layar, tapi gak ada suara

Penyebab 1: Chrome gak boleh bunyi sebelum layar disentuh (aturan autoplay). Obat: tap layar sekali, ulangi.

Penyebab 2: edge-tts gagal keinstall dan FISH_API_KEY kosong. Obat: cek dengan diag, lalu isi Fish Audio (bagian 04b).

Penyebab 3: volume media HP kecil / speaker ke-mute. Cek pakai video YouTube dulu.

Muncul tulisan “Otak gue lagi gangguan: 401 / 403”

Penyebab: API key salah, kosong, atau kena limit provider.

grep -E '^LLM_(BASE_URL|MODEL)=' ~/kosmate/.env
grep -c '^LLM_API_KEY=sk-' ~/kosmate/.env

Base URL harus diakhiri /v1 dan gak boleh ada /chat/completions di belakangnya.

“…model not found” atau 404

Penyebab: nama model gak ada di provider lu.

curl -s https://api.teamorouter.com/v1/models \
  -H "Authorization: Bearer $(grep '^LLM_API_KEY=' ~/kosmate/.env | cut -d= -f2)" \
  | grep -o '"id":"[^"]*"' | head -20

Tempel salah satu ID yang muncul ke LLM_MODEL.

Server mati sendiri kalau layar mati / app ditutup

Penyebab: Android bunuh proses Termux.

Obat: 1) termux-wake-lock (sudah otomatis lewat termux-start.sh), 2) Termux → Battery → Unrestricted, 3) di MIUI: buka recent apps → tahan Termux → kunci (ikon gembok).

“Address already in use”

Penyebab: server lama masih jalan.

pkill -f "kos.app:app"
sleep 1
bash scripts/termux-start.sh

Atau pakai port lain: bash scripts/termux-start.sh 8081

Suaranya kepotong / jawabannya kacau

Penyebab: model gratis sedang antre, atau balasan kepanjangan.

Obat: ganti LLM_MODEL ke gemini-3.5-flash-lite; atau minta dia jawab lebih pendek (“singkat aja”); atau naikin jeda dengerin di gear.

Memori gak pernah nambah

Normal: ekstraksi jalan tiap 4 giliran atau kalau lu bilang inget / catat / besok / deadline. Cek langsung:

curl -s http://127.0.0.1:8080/api/memory/facts | head -c 400

Kalau kosong terus padahal udah ngobrol banyak, berarti model lu males bikin JSON — ganti model fallback.

Dia denger suaranya sendiri / jawaban muter-muter

Penyebab: speaker terlalu dekat mic, dan HP gak punya echo cancellation di browser.

Obat: jauhkan speaker dari HP minimal 1 meter, kecilin volume, atau nyalakan dengerin otomatis = mati (jadi lu kontrol manual pakai orb).

“Permission denied” waktu jalanin script
cd ~/kosmate
chmod +x run.sh scripts/*.sh
bash scripts/install.sh
11 — RAWAT

Biar tahan berbulan-bulan

Baterai. Dicas 24/7 bikin baterai kembung. Idealnya batasi cas 60–80% (butuh root + app Battery Charge Limit). Tanpa root: colok ke smart plug + timer (nyala 2 jam, mati 2 jam), atau lepas casing dan tagakkan HP biar gak panas.

Layar. Browser butuh layar nyala. Fully Kiosk bisa bikin layar redup banget (brightness 1%) dengan background gelap — hemat dan gak nyilauin mata waktu tidur.

Backup memori mingguan → http://127.0.0.1:8080/api/export → simpan JSON. Ini isi “ingatan” dia satu-satunya. File aslinya: ~/kosmate/data/kosmate.db

Update kode (kalau gw kirim versi baru): timpa folder kos/ dan web/ saja. Jangan hapus data/ — di situ memorinya.

Log kalau ada error: tail -50 ~/kosmate/data/boot.log (kalau jalan lewat autostart).
